# CareerFlow

CareerFlow is a job application CRM built with Google Apps Script and Google Sheets.

It helps job seekers track applications, manage application statuses, search records, update details, delete entries safely, and view live dashboard statistics.

## Features

- Add job applications through a custom sidebar
- Automatically generate application IDs
- Search applications by company
- Edit existing application records
- Delete applications with confirmation
- Live dashboard totals
- Automatic dashboard refresh
- Google Sheets as the data layer
- Google Apps Script backend
- HTML and CSS sidebars
- Git and GitHub version control

## Current Dashboard Metrics

- Total applications
- Interviews
- Offers
- Rejected applications
- Recent applications
